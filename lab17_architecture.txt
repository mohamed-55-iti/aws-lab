Traffic Flows:
──────────────
1. Internet → IGW → Bastion (VPC-A)
2. Bastion → TGW → App Server (VPC-B)
3. Bastion → TGW → DB Server (VPC-C)
4. App → TGW → DB Server
5. VPC-B/C → TGW → VPC-A → NAT → Internet (Outbound)

Route Tables:
─────────────
VPC-A: 0.0.0.0/0 → IGW
       172.16.0.0/16 → TGW
       192.168.0.0/16 → TGW

VPC-B: 0.0.0.0/0 → TGW (→ NAT via VPC-A)
       10.0.0.0/16 → TGW
       192.168.0.0/16 → TGW

VPC-C: 10.0.0.0/16 → TGW
       172.16.0.0/16 → TGW

Security Groups:
────────────────
Bastion: SSH (22) from 0.0.0.0/0
App:     All TCP from VPC-A, VPC-C
DB:      All TCP from VPC-A, VPC-B
